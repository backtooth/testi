# Salasauna

Minuutin selainpeli: etsi vihjeiden avulla perjantain salasauna, kerää kaupalla kaljoja ja saavu oikeaan taloon täsmälleen klo 18.00.

## Pelaaminen

- WASD / nuolinäppäimet: liiku
- Q: koputa ja kysy vihjettä
- E: astu sisään (lopullinen valinta)

Peli toimii myös kosketusnäytöllä. Staattinen toteutus ei vaadi käännösvaihetta ja soveltuu suoraan GitHub Pagesiin.
