# Hello World

Yksinkertainen Hello World -verkkosovellus ilman asennettavia riippuvuuksia.

## Käynnistäminen

Avaa `index.html` selaimessa. Sivulla näkyy **Hello World!**.

## Linnan piiritys

Uusi vuoropohjainen kortti- ja piirityspeli löytyy kansiosta `castle-siege/`.
Pelaa hyökkääjänä tai puolustajana tietokonetta vastaan. Avaa `castle-siege/index.html` paikallisesti tai [pelaa GitHub Pagesissa](https://backtooth.github.io/testi/castle-siege/).

Peli toimii staattisena ilman asennuksia. Sääntötestit: `node castle-siege/check.cjs`.
